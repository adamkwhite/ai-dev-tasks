# AI Dev Tasks - Claude Context

## Project Overview

**Type**: Development workflow tools for Cursor AI editor  
**Purpose**: Structured approach to feature development using AI assistance  
**Status**: Complete toolkit for AI-assisted development workflows

## Tech Stack

- **Format**: Markdown Command files (.mdc) for Cursor AI agent
- **Usage**: Cursor AI editor integration
- **Workflow**: Structured task processing with checkpoint verification

## Key Features

- PRD generation from user prompts with clarifying questions
- Automated task list generation breaking PRDs into actionable items
- Step-by-step task processing with checkpoint verification
- Structured workflow enforcing review gates between tasks

## Usage Workflow

1. **Create PRD** → Generate product requirements document
2. **Generate tasks** → Break PRD into actionable items  
3. **Process tasks** → Execute tasks one-by-one with verification
